Copas prompt
ini ke AI kamu

Cursor, Claude, Lovable, Bolt, v0. Bebas.

Tambahkan ke website ini:

1. Favicon dari logo saya: favicon.ico,
   icon 32x32, apple-touch-icon 180x180

2. Meta title unik tiap halaman,
   maks 60 karakter: "[Brand]: [manfaat]"

3. Meta description 140-160 karakter,
   isinya manfaat + ajakan

4. OG image 1200x630 + tag og:title,
   og:description, og:image (URL absolut),
   og:url, twitter:card=summary_large_image

Taruh semua di <head>.
